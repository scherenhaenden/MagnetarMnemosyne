# Contributing to Magnetar Mnemosyne

## Development Setup

1. Clone the repository.
2. Create or activate the local environment.
3. Install dependencies as needed.
4. Start the application with `python3 main.py`.

## Working Rules

- Read `README.md`, `PLAN.md`, `RULES.md`, and `STATUS.md` before starting significant work.
- Keep tasks aligned with the allowed states.
- Update `BITACORA.md` when making meaningful changes, decisions, or exceptions.
- Add or update tests for core logic changes.

## Pull Request Expectations

- Reference the relevant task IDs.
- Summarize what changed and why.
- Include test evidence.
- Ensure related governance documents remain accurate.
