# Work-In-Progress Guidelines for Magnetar Mnemosyne

## WIP Policy

- Default WIP limit per contributor or AI agent: `2` tasks in `in_progress`.
- Prefer finishing or re-queuing existing work before pulling new tasks into active execution.

## Exception Handling

- Any approved WIP overflow must be documented in `BITACORA.md`.
- The reason for the exception and the expected duration must be explicit.

## Task Selection

- Pull from `ready` tasks first.
- Do not start blocked work unless the work is specifically to resolve that blocker.
- Move tasks to `in_review` as soon as implementation is complete enough for validation.
