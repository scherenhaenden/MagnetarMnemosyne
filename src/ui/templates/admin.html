Descripción del Audio

Metadatos básicos y payload estructurado de la conversación.

Qué poner en `conversation_json`

Define `speakers` con `reference_audio_url` y `reference_text`, y luego el `dialogue` con bloques `Speaker (...)` o una lista `turns`. Hay un ejemplo listo en examples/audios/f5tts-audio-template.txt.

{
  "speakers": [
    {
      "id": "teacher",
      "label": "Teacher",
      "descriptor": "calm Spanish woman from Madrid",
      "reference_audio_url": "/ruta/profe.wav",
      "reference_text": "Buenos días. ¿Cómo te llamas?"
    },
    {
      "id": "student",
      "label": "Student",
      "descriptor": "young girl, slightly nervous",
      "reference_audio_url": "/ruta/alumna.wav",
      "reference_text": "Hola. Me llamo Lía."
    }
  ],
  "dialogue": "Teacher (calm Spanish woman from Madrid):\n[warmly]\nBuenos días. ¿Cómo te llamas?\n\nStudent (young girl, slightly nervous):\n[nervous]\nHola. Me llamo Lía."
}
